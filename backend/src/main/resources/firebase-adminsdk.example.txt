Firebase Admin SDK template reference only.
Do not rename this file to .json in git.

Expected JSON keys in your local private file:
- type
- project_id
- private_key_id
- private_key
- client_email
- client_id
- auth_uri
- token_uri
- auth_provider_x509_cert_url
- client_x509_cert_url
- universe_domain

Setup:
1. Firebase Console -> Project Settings -> Service accounts
2. Generate new private key
3. Save it locally as:
   backend/src/main/resources/firebase-adminsdk.json
4. Never commit that .json file to git

# Question Tool

Danh sách câu hỏi test chatbot theo từng role, viết theo văn phong tự nhiên, tiếng Việt và phù hợp để hỏi thử trực tiếp.

Giá trị tham chiếu dùng xuyên suốt:
- Sinh viên: `Vũ Hải Thanh` - `SE074721`
- Giảng viên: `GV115211`
- Lớp: `SE18B01-PRF192`, `SE18B02-MAD101`, `SE18B05-PRF192`
- Môn học: `PRF192`, `MAD101`, `DBI202`
- Phòng học: `A312`, `A501`, `A604`
- Học kỳ: `SP26`
- Ngành: `Công nghệ thông tin`, `Kỹ thuật phần mềm`, `An toàn thông tin`

Lưu ý:
- Các câu hỏi tra cứu dùng dữ liệu thật đang xuất hiện trong repo để dễ test.
- Các câu hỏi tạo mới và cập nhật có thể dùng mã `TEST_*` để tránh ảnh hưởng dữ liệu đang dùng.
